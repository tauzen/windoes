# Outcome

Right-clicking a taskbar button, or pressing the menu key or Shift+F10 on it, opens a Windows 98 menu with Restore, Minimize, Maximize and Close; items that do not apply are disabled. Close works for every window, including Winamp when its page fails to load. Merged in PR #150 (`05f9747`); a browser test covers placement, keyboard use, states, dismissal and the blank-Winamp close.
