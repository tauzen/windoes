# Outcome

The inline scripts of all five apps (Winamp, Paint, Minesweeper, Solitaire, Minecraft) now live in `<app>/app.js`, which one ESLint block and the strict `tsconfig.json` glob cover; no app `index.html` has an inline script. Merged in PRs #133–#137 (last merge `75481ab`). The loader is a classic `<script src="app.js">`, because the app suites open `index.html` over `file://`, where Chromium blocks module scripts. The owner checked Solitaire's F2 New Game in the shell on the live site; it works (a Playwright key press inside the frame did not trigger it, so that probe is not a valid test).
