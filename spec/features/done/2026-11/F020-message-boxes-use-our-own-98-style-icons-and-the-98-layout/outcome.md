# Outcome

Error, warning and information boxes show our own pixel-drawn 32x32 icons in the Windows 98 style (`windoes/shell/MessageBoxIcon.jsx`), size to their text up to a maximum, and centre one-line text on the icon; the Run dialog right-aligns its buttons, and the file chooser overwrite warning uses the same icon. Merged in PR #154 (`7fc5853`). No Microsoft art was copied, traced or extracted.
